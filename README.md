# Developer & Analyst Portfolio

A professional, high-performance portfolio website styled as a field notebook and instrument panel, featuring smooth animations and a live wait-time calculator.

Built with **Next.js 14 (App Router)**, **TypeScript**, **Tailwind CSS**, and **Framer Motion**.

## 🚀 Getting Started

Start the local development server:

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) with your browser to see the live site.

## 📁 Project Structure

* `app/` — Pages, dynamic case studies, and playground routes.
* `components/` — Modular and reusable React components.
* `lib/data.ts` — The single source of truth for all portfolio data and copy.

## 🛠️ Features

* **Interactive Elements**: Live queueing-theory model calculator.
* **Aesthetics**: Glassmorphism, animations, and high-contrast dark theme.
* **SEO & Performance**: Statically generated pages, automated Open Graph social share image generation, dynamic sitemaps, and full responsive layout.
